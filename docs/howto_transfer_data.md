# Transferring files via Funet FileSender

To transfer files from [CSC’s computing environment](https://urn.fi/urn:nbn:fi:lb-2026090301) via Funet FileSender (without downloading them first to your local computer), you can use the graphical desktop interface in your web browser.

Log in to the [web interface of CSC’s computing environment](hhttps://docs.csc.fi/computing/webinterface/).

In Apps, select Desktop. Request for a new desktop and start the desktop as soon as it is initialized for you.

In the Linux desktop, open the web browser and go to filesender.funet.fi. Upload files from your directory in the computing environment and send them normally.
